# TEAZ 카운터

https://kjysss2.github.io/teaz/

Teaz 한국어 사이트의 캐릭터 카드에 표시되는 종이비행기 숫자(`message_count`)를 공개 API `https://api.myteaz.io/chat/characters`에서 수집합니다. 페이지 이동 커서를 끝까지 순회하며 캐릭터 ID로 중복을 검사합니다. 로그인이나 비공개 데이터는 사용하지 않습니다.

- 메시지 누적 합계, 이전 관측 대비 순증, 캐릭터별 순위·검색·정렬
- 일별·주별·월별 누적 및 순증 그래프, 일별 기록 CSV
- 매일 00:00 KST 기준. 18:17·21:17·23:17에 미리 실행을 요청하여 자정까지 대기하고, 00:00 예약도 보완으로 둡니다. GitHub 자체 예약 지연·누락 가능성은 남아 있습니다.
- 자정부터 2분 미만에 시작·완료된 값만 기준 기록으로 저장합니다. 그보다 늦으면 작업을 실패 처리하고 해당 날짜는 미수집으로 남깁니다. 실제 시각을 00:00으로 바꾸지 않습니다.
- 기준 기록은 덮어쓰지 않습니다. `--force`는 별도의 참고 기록을 추가하며 자정 그래프·순증에는 포함하지 않습니다. 일반 코드 push는 수집 없이 배포만 합니다.
- 실패·잘못된 카운터·작품 수 20% 이상 감소 시 기존 데이터를 보존하고 작업을 실패 처리합니다. 실제 수집 시각을 화면에 표시합니다.
- 브라우저는 1분마다 다시 읽으며 PC를 켜 둘 필요가 없습니다.

서로 다른 날짜의 유효한 자정 기준 기록이 있어야 순증이 나옵니다. 10월 19일 수동 기록과 10월 20일 05:27 기록은 참고 기록으로 보존하고 자정 계산에서 제외했습니다. 과거 자정 값은 복구하거나 소급 생성할 수 없습니다. 합계 증감에는 작품 목록 변화가 포함되며, 신규 캐릭터의 개별 순증은 비교 기준이 없어 표시하지 않습니다. 메시지 카운터는 매출·이용자 수가 아닙니다.

## 수동 실행

Actions → Collect and publish Teaz counter → Run workflow. force 체크 시 현재 참고값을 추가합니다. force 없이 기준 시간 밖에서 실행하면 실패합니다. 공개 저장소에서 활동이 60일 이상 없으면 GitHub가 예약을 비활성화할 수 있습니다.

## 로컬

Node.js 22 이상, 외부 패키지 불필요. `node scripts/collect.mjs` 또는 `node scripts/collect.mjs --force`. 검증: `node --test tests/*.test.mjs`.
원작 수는 원작명의 한글 정규화·앞뒤/연속 공백 정리 후 중복을 제거하여 집계하며, 원작명이 없는 항목은 제외합니다.
