# TEAZ 카운터

https://kjysss2.github.io/teaz/

Teaz 한국어 사이트의 캐릭터 카드에 표시되는 종이비행기 숫자(`message_count`)를 공개 API `https://api.myteaz.io/chat/characters`에서 수집합니다. 페이지 이동 커서를 끝까지 순회하며 캐릭터 ID로 중복을 검사합니다. 로그인이나 비공개 데이터는 사용하지 않습니다.

- 메시지 누적 합계, 이전 관측 대비 순증, 캐릭터별 순위·검색·정렬
- 일별·주별·월별 누적 및 순증 그래프, 일별 기록 CSV
- 매일 00:00 KST 수집 목표. 보완 실행 00:17, 00:37, 01:07. GitHub Actions는 정시 실행을 보장하지 않아 실제 반영이 늦어질 수 있습니다.
- 이미 해당 날짜 00:00 이후에 수집했으면 건너뜁니다. 수동 실행의 force 옵션으로 같은 날짜를 교체할 수 있습니다.
- 실패·잘못된 카운터·작품 수 20% 이상 감소 시 기존 데이터를 보존하고 작업을 실패 처리합니다. 실제 수집 시각을 화면에 표시합니다.
- 브라우저는 1분마다 다시 읽으며 PC를 켜 둘 필요가 없습니다.

최초 수집은 기준값입니다. 두 날짜의 기록부터 순증이 나옵니다. 과거 데이터는 소급 생성하지 않습니다. 합계 증감에는 작품 목록 변화가 포함되며, 신규 캐릭터의 개별 순증은 비교 기준이 없어 표시하지 않습니다. 주별·월별 수치는 해당 기간 마지막 관측값을 기준으로 비교합니다. 메시지 카운터는 매출·이용자 수가 아닙니다.

## 수동 실행

Actions → Collect and publish Teaz counter → Run workflow. 수집과 배포 상태는 실행 로그에서 확인합니다. 실패 시 다음 보완 예약 또는 수동 실행으로 재시도합니다. 공개 저장소에서 활동이 60일 이상 없으면 GitHub가 예약을 비활성화할 수 있습니다.

## 로컬

Node.js 22 이상, 외부 패키지 불필요. `node scripts/collect.mjs` 또는 `node scripts/collect.mjs --force`. 검증: `node --test tests/*.test.mjs`.
`n원작 수는 원작명의 한글 정규화·앞뒤/연속 공백 정리 후 중복을 제거하여 집계하며, 원작명이 없는 항목은 제외합니다. 요약·그래프·일별 기록·CSV에 표시하며 매일 같은 수집 기록에서 계산합니다.
